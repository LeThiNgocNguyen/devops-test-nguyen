# devops-test-nguyen

## Description

This project is a DevOps CI/CD practice project.

The CI/CD process is:

Developer → GitHub → Jenkins → Build → Deploy → Telegram

## Technologies

- HTML
- CSS
- JavaScript
- GitHub
- Jenkins
- Vercel
- Telegram Bot

## Pipeline

1. Developer pushes code to GitHub
2. GitHub triggers Jenkins
3. Jenkins checks out the source
4. Jenkins installs dependencies
5. Jenkins builds the project
6. Jenkins deploys the website
7. Telegram sends deployment notification
